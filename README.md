* Organizador de Arquivos
Este projeto foi criado em Python para organizar automaticamente os arquivos de uma pasta, separando-os por tipo e extensão. 
O programa verifica cada arquivo e o move para uma pasta específica, como documentos, imagens, vídeos, áudios, compactados e código.

* Como funciona
Ao executar o script, o usuário informa o caminho da pasta que deseja organizar. 
O programa percorre os arquivos dessa pasta, identifica a extensão de cada um e os move para pastas criadas automaticamente, como:

Textos
Word
PDF
Excel
PowerPoint
Fotos
Audios
Videos
Compactados
Executaveis
Codigo
Fontes

* Como usar
1. Instale o Python no computador.
2. Abra o terminal.
3. Acesse a pasta do projeto.
4. Execute:
python organizador_de_arquivos.py
5. Digite o caminho da pasta que deseja organizar.

* Requisitos
Python 3 instalado
Permissão para criar pastas e mover arquivos
Acesso à pasta que será organizada

* Importante
Antes de executar o programa, confirme o caminho da pasta, pois os arquivos serão movidos para outras pastas de forma permanente.
